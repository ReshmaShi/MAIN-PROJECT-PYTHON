# Kickstarter Funding Trends and Success Analysis

## Project Overview
This project analyzes Kickstarter project data from 2016–2018 to understand funding trends, project performance, and the factors associated with project success. The analysis explores how funding goals, pledged amounts, backers, categories, and project duration relate to project outcomes.

## Objectives
- Analyze the overall success and failure rates of Kickstarter projects.
- Identify categories with higher project success rates.
- Understand the relationship between funding goals, pledged amounts, and backers.
- Examine how funding goals influence project success.
- Identify key trends and insights to support better project planning.

## Dataset
- **Source:** GitHub
- **Period:** 2016–2018
- **Total Records:** 113,270 projects
- **Original Columns:** 11
- **Columns After Data Preparation:** 17

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Power BI

## Project Workflow

1. **Data Loading:** Imported the Kickstarter dataset into Python using Pandas.
2. **Data Cleaning:** Checked missing values, duplicate records, and data types.
3. **Data Transformation:** Converted date columns and created additional analytical columns.
4. **Exploratory Data Analysis (EDA):** Explored project states, categories, countries, funding goals, pledged amounts, and backers.
5. **Univariate Analysis:** Studied individual variables to understand their distributions.
6. **Bivariate Analysis:** Examined relationships between project variables.
7. **Category Analysis:** Compared project counts and success rates across categories.
8. **Goal Analysis:** Evaluated how different funding goal ranges affected success rates.
9. **Correlation Analysis:** Examined relationships between funding goals, pledged amounts, and backers.
10. **Visualization:** Created charts to identify important patterns and trends.
11. **Power BI Dashboard:** Developed an interactive dashboard to present key findings and project performance.

## Key Findings

- Failed projects accounted for the highest proportion of projects, followed by successful projects.
- Games had the highest number of successful projects, while Comics recorded the highest success rate.
- Projects with lower funding goals generally had higher success rates.
- Successful projects had a higher average number of backers compared to other project states.
- Pledged amounts showed a strong relationship with funding goals, while funding goals had almost no linear relationship with the number of backers.
- The analysis highlighted the importance of realistic funding goals in improving project success.

## Dashboard
An interactive Power BI dashboard was developed to explore:
- Project status distribution
- Category-wise project success rates
- Funding goal performance
- Pledged amounts and backer trends
- Project performance across different categories

## Conclusion
The analysis shows that setting realistic funding goals is an important factor associated with Kickstarter project success. Category-wise analysis also revealed that having the highest number of successful projects does not necessarily mean having the highest success rate. These insights help understand funding patterns and project performance on crowdfunding platforms.
